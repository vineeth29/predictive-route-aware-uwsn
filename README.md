# Adaptive MAC Protocol for Underwater Wireless Sensor Networks

## Project Overview

This project investigates an adaptive Medium Access Control (MAC) strategy for Underwater Wireless Sensor Networks (UWSNs).

The project will use NS-3.41 and Aqua-Sim NG as the simulation framework.

## Project Goals

- Study existing underwater MAC protocols.
- Establish reproducible baseline simulations.
- Design an adaptive MAC selection mechanism.
- Evaluate the proposed approach under different network conditions.
- Compare throughput, packet delivery ratio, delay, energy consumption, and collision behavior.

## Environment

- Ubuntu 24.04 LTS
- NS-3.41
- Aqua-Sim NG
- C++
- Python for result analysis
